## Description

My very own NixOS configuration for the `jinnnn` host (x86_64-linux). Contains device-specific system configuration and user home-manager configuration for `meher`.

## Structure

### System Configuration (`system/jinnnn/`)

- `boot.nix` — Boot loader
- `docker.nix` — Docker daemon
- `fonts.nix` — System fonts
- `hardware_configuration.nix` — Auto-generated by `nixos-generate-config`, do not edit directly
- `kanata.nix` — Kanata key remapping
- `locale.nix` — Locale settings
- `networking.nix` — Network configuration
- `openssh.nix` — SSH daemon
- `packages.nix` — System packages
- `stylix.nix` — Stylix theming
- `syncthing.nix` — Syncthing service
- `users.nix` — User definitions
- `windscribe.nix` — Windscribe VPN
- `plymouth-theme/` — Plymouth boot splash theme (`boot-splash.png`)

## rebuild

```bash
sudo nixos-rebuild switch --flake ~/nixconfig#jinnnn
```
